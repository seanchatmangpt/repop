# 01-abi — Wave-2 Plan, Lane P1: @repop/abi Pinned Layouts and Parity

Standing: PARTIAL

## Charter

Define, generate, and pin the 64-byte binary frames that cross the kernel/worker/client
boundary: `IntentFrame`, `HyperplaneRegister`, `ReceiptFrame` (envelope). Produce one
source of truth in Rust (`crates/abi`), a generated TypeScript mirror (`packages/abi`),
and a two-leg parity gate that fails closed on any drift between them.

Precedent: `cgap-aoq/src/{header.rs, generated_aoq_header_layout.rs, pin_table.rs}` +
TS mirror (R10 step 1, E1/E2 in `wave-1-resolutions.md`). No hand-written TS layout
types — TS is projected, never authored beside the Rust truth.

Laws inherited (resolutions `## Laws all Plan lanes inherit`): zero-JSON on this
surface; fixed-width LE only; Chicago testing; courts carry mutation legs; fail-closed
typed refusals for unknown `alg_id` or version.

## Resolved decisions

Locked by Wave-1 resolutions; this lane refines, never contradicts.

1. **64B ReceiptFrame envelope** (R3): the client tier emits a 64-byte envelope whose
   payload binding is a 32B keyed-BLAKE3 digest of the 229B `UnsealedReceipt`
   (`cgap-crypto` layout, R2). Full 229B unsealed bodies and the 3309B ML-DSA-65 seal
   (alg 0x0001) stay server-side at the trust boundary; the wire surface here is 64B.
2. **alg_id upgrade seam** (R3): 2-byte algorithm-ID field; `0x0000` = keyed-BLAKE3
   UnsealedReceipt binding, `0x0001` = ML-DSA-65 sealed receipt. Unknown `alg_id`
   decodes as a typed `UnsupportedAlgorithm` refusal — never a silent pass-through.
3. **align(64)** (R10, cgap-core `CgapFrameHeader` precedent, R2): every frame is
   exactly 64 bytes, cache-line aligned, compile-time `const` size asserts in Rust.
4. **Little-endian** everywhere (cgap-core codec precedent); BE WIR0 slot header is
   P6's concern at the SAB ring, translated at the transport seam, not here.
5. **FNV-1a32 integrity digest** at byte offset 60, over bytes `[0x00, 0x3C)` —
   the first 60 bytes of the frame. Digest covers all fields except itself plus the
   4 trailing pad/reserved bytes; any mutation in `[0x00,0x3C)` flips verification.
6. **Generated TS mirror** (R11 determinism): `scripts/gen_ts_mirror.py` reads the
   Rust layout module (or an intermediate table it emits) and writes
   `packages/abi/src/generated/*.ts` with a determinism stamp — byte-identical
   regeneration, no wall-clock in output (E11 `new Date()` violation is the named
   anti-pattern).
7. **FNV-1a32 constants**: offset basis `2166136261`, prime `16777619`, per
   standard FNV-1a; pinned as `const` in both Rust and generated TS with parity
   assertion.

### ReceiptFrame 64-byte map (offset, width, field)

```text
0..2    u16 magic      0x5246 ("RF")
2..4    u16 version    layout version, starts at 1
4..6    u16 alg_id     0x0000 keyed-BLAKE3 | 0x0001 ML-DSA-65
6..8    u16 flags      reserved, zero on write, ignored-but-pinned on read
8..40   [32] u8        keyed-BLAKE3 binding of the 229B UnsealedReceipt
40..56  [16] u8        admissions Merkle root prefix (cgap-crypto R2)
56..58  u16 frame_seq  monotonic per-issuer sequence (mod 2^16)
58..60  u16 payload_len reserved for future variable-length annex; zero now
60..64  u32 fnv1a32    digest over bytes [0x00, 0x3C), LE
```

IntentFrame and HyperplaneRegister follow the same 64B envelope discipline with their
own magic values; exact field maps are an implementation deliverable of this lane
using the same offsets 60/64 digest rule. No frame exceeds or under-fills 64 bytes.

## Owned files

Lane P1 owns exactly these paths; everything else is read-only reference.

### `crates/abi/src/lib.rs`
- Crate root: no_std kernel-compatible module declarations, `#![deny(missing_docs)]`
  on public layout items, re-exports of the three frame codecs.

### `crates/abi/src/frames.rs`
- Hand-authored law: field constants (offsets, widths, magics, `ALG_ID_*`, FNV
  constants), `#[repr(C, align(64))]` frame structs, `const` size asserts
  (`core::mem::size_of == 64`), encode/decode to/from `&[u8; 64]`, typed decode
  errors (`BadMagic`, `BadVersion`, `UnsupportedAlgorithm`, `DigestMismatch`),
  digest compute/verify over `[0x00, 0x3C)`.

### `crates/abi/src/generated_layout.rs`
- Generated single-source-of-truth table (precedent
  `generated_aoq_header_layout.rs`): offset/width/type rows for all three frames,
  regenerated by `scripts/gen_ts_mirror.py` from `frames.rs` annotations — this file
  is what the TS mirror and the pin table both derive from. Do not hand-edit.

### `crates/abi/src/pin_table.rs`
- Compile-time pins (precedent `pin_table.rs`): `const` assertions that every offset
  in the table matches `repr(C)` placement, 64-byte total, align 64, digest span.

### `crates/abi/tests/layout_courts.rs`
- Chicago courts: golden-byte fixtures (SplitMix64 seed `0xA20C_0FFE_E5A7_E000`
  per R4), round-trip encode/decode, fail-closed decode of every mutation of the
  golden bytes (single-bit and byte-swap mutations must each produce a typed error),
  zero-alloc encode path assert.

### `crates/abi/Cargo.toml`
- no_std, `cgap-blake3` scalar wasm path as the only dependency (vendored per R11);
  no std, no serde, no JSON anywhere in this crate.

### `packages/abi/src/generated/layouts.ts`
- Generated TS mirror: byte-offset constants, `DataView`-based read/write helpers,
  typed decode result unions mirroring Rust errors, FNV-1a32 implementation,
  `alg_id` union type. Fully generated; header comment names the generator command.

### `packages/abi/src/index.ts`
- Package entry: re-export generated surface + tiny hand-written `isDecodeError`
  guard; package shape mirrors `@srve/avion` raw-TS-entry convention (R6).

### `packages/abi/test/parity.test.ts`
- Unit project (jsdom — no worker/WASM here, per R6 project law): golden-byte fixture
  shared by both legs, decode/encode parity against Rust-emitted golden bytes.

### `scripts/gen_ts_mirror.py`
- Generator: parses `generated_layout.rs` table → emits `layouts.ts`; deterministic
  output (no timestamps); `--check` mode that regenerates and exits non-zero on diff.

### `verify_parity.py`
- Two-leg gate driver (see Gates); exits 0 only when both legs pass; loud typed
  failure naming the leg and the diverging frame/field.

## Gates

**Parity gate, two legs — both required, fail-closed (`verify_parity.py`):**

1. **Generated-mirror drift leg**: `cargo test -p repop-abi` (Rust courts) and
   `scripts/gen_ts_mirror.py --check` (regenerated TS byte-identical to committed).
   Any drift in the generated mirror = exit non-zero naming the row.
2. **Golden-byte leg**: SplitMix64-seeded fixture (`0xA20C_0FFE_E5A7_E000`, R4)
   produces deterministic frame bytes; Rust encodes, TS must decode to identical
   field values, TS re-encodes, Rust must decode to identical bytes. Byte-exact
   both directions.

**Mutation legs (anti-vacuity for the gate itself):**
- Flip any byte in the golden fixture's `[0x00,0x3C)` → parity gate MUST fail with
  `DigestMismatch`. If it still passes, the gate is vacuous — exit 1.
- Change an offset in `generated_layout.rs` without touching `frames.rs` → the
  pin-table compile assert or the drift leg MUST fail. If neither does, exit 1.
- Feed TS decode a frame with `alg_id = 0xFFFF` → must yield `UnsupportedAlgorithm`,
  never a default or pass-through.

## Dependencies

- **P2** (hyperplane solver): consumes IntentFrame/HyperplaneRegister codecs.
- **P3** (CAS + receipt emission): consumes ReceiptFrame envelope + alg_id seam;
  emits the 229B UnsealedReceipt this frame binds.
- **P4** (kernel wasm): builds this crate no_std for wasm32-unknown-unknown;
  raw linear-memory exchange requires our fixed 64B buffers.
- **P6** (SAB ring): slots carry these 64B frames; LE/BE translation happens at
  its transport seam.
- **P9** (message protocol): binary frame router routes on our magic/version
  fields; zero-JSON law is enforced by this crate's shape.
- **P16/P17** (ggen pack ontology + gates): pack ships after ABI freeze (R9, R10
  step 7); ABI vocabulary is the pack's namespace input.
- Blocked-by order: this lane is first (R10 step 1); P2–P4/P6/P9 may not land
  frame-handling code before `verify_parity.py` exits 0 on both legs.
